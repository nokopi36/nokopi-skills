# FTB Quests のバージョンと保存形式

**クエストを書く前に、パックに入っている FTB Quests のバージョンを確認する**（`mods/ftb-quests*.pw.toml` の filename やバージョン）。
形式を間違えると読み込まれないか、ゲーム内で上書きされて消える。

| FTB Quests | Minecraft | 保存形式 | 翻訳テキスト |
|---|---|---|---|
| 2001.x | 1.20.1 | SNBT | チャプターファイル内に直接（title／subtitle／description フィールド） |
| 2100.x 〜 2101.x | 1.21 / 1.21.1 | SNBT | `quests/lang/<locale>.snbt` に分離（`chapter.<ID>.title` 形式のキー） |
| 26.x | 26.1 以降 | **JSON5**（SNBT は使われない） | `quests/lang/` 配下で、種類・チャプターごとに複数ファイルに分割 |

- このスキルの `quests.py` と `ftb-quests/` の資料は **1.21 系（SNBT + lang 分離）** 向け
- 1.20.1 や 26.x のパックでクエストを作るときは、その版のファイルを 1 つゲーム内で作って保存し、形式を実物で確認してから同じ形で書く。
  資料と実物が食い違ったら実物を正とする
- 2101.1.x は古いクエストブックを読み込むと、翻訳テキストを自動で `lang/en_us.snbt` に移す
- 新しく作るチャプターのファイル名はチャプター名から付けられる（`filename` フィールドとファイル名は必ず一致させる）

## ゲーム内エディタとの往復
- 配置（x, y）や見た目の微調整は、ゲーム内で編集モード（クエストブックの設定から）にして行う方が速い
- ゲーム内で保存すると、ファイルが書き直される（フィールドの並び順や数値の書式が変わる）。
  手で書いたファイルとゲーム内の保存が衝突しないよう、**ゲーム内で編集したら、そのファイルを読み直してから**続きを書く
- 開発中のパックは、ゲーム内編集の結果を `run/` ではなくパックの `config/ftbquests/` に戻す必要がある。
  テスト用インスタンスで編集した場合は、そのインスタンスの `config/ftbquests/quests/` をパックへコピーする
