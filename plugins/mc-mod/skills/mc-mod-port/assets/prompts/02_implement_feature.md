## 進め方
1. **計画を先に出す**: 作成・変更するファイル、使うクラス（`refs/` のどのファイルで確認したか）、
   SPEC から逸脱しそうな点を列挙して、確認を待ってください。
2. 承認後に実装。
3. `./gradlew build` が通るまで直す。
4. 数値ロジックがあれば GameTest を追加して確認。
5. 報告:
   - 変更ファイル一覧
   - SPEC の各項目の「実装済み / 未実装 / 逸脱（理由）」チェック表
   - `./gradlew runClient` での手動確認手順
   - 次に実装すべき機能の提案
